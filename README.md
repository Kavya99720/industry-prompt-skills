# Industry Prompt Skills (CEL-53)

## Task

A prompt-writing skill for each of 10 industries, with prompts validated against an eval.json of 20-30 compliance checks per industry.

Acceptance criteria:

- [ ] A skill per assigned industry, covering its scenarios, vocabulary and compliance rules
- [ ] An eval.json per industry with 20 to 30 compliance test cases
- [ ] Prompts generated by the skill validated against the evals, with results recorded
- [ ] Failing cases fed back into the skill until the evals pass
- [ ] Folder location shared with the team

Merging into the platform is out of scope for this task.

## Industries

pharmacy, healthcare, retail, finance, education, logistics, hr, banking, real-estate, travel.

Each skill writes system prompts for voice and chat agents. This folder is separate from the platform codebase.

## Folder layout

```
industries/<slug>/brief.md            the industry's scenarios (S-xx), rules (R-xx), vocabulary, escalation, data handling and open questions
industries/<slug>/eval.json           20-30 compliance checks; read-only once approved
industries/<slug>/results/            saved validation runs
.claude/skills/<slug>-prompt-writer/  the industry skill: SKILL.md and a references/ folder
.claude/skills/                       the steps below, each as a skill
.claude/agents/eval-judge.md          the grader that marks each check pass or fail
.claude/hooks/                        blocks edits to approved eval.json files and validates edited ones
docs/shared/baseline-rules.md         rules that apply to every industry's voice agent
docs/shared/eval-schema.md            the eval.json format, the same for every industry
docs/DECISIONS.md                     decisions log
scripts/validate_eval.py              checks that an eval.json is valid
tests/                                automated tests (pytest)
```

## Steps for each industry

1. **grill-me**: ask the owner questions about the industry and record the answers in docs/DECISIONS.md.
2. **brainstorm**: list caller scenarios, edge cases, compliance risks and attack attempts.
3. **spec-first**: write the brief (industries/<slug>/brief.md) and get it approved.
4. **write-evals**: turn the brief into 20-30 compliance checks in eval.json, get them approved, then lock the file.
5. **Write the skill**: create `.claude/skills/<slug>-prompt-writer/`.
6. **run-evals**: generate a prompt with the skill, grade it against every check, and save the results.
7. **Fix the skill** for each failed check, then run step 6 again until every check passes.
8. **release-check**, then commit.

Rules:

- Never edit a locked eval.json to make a prompt pass. Fix the skill instead. Change an eval only if it is wrong, and record the reason in docs/DECISIONS.md.
- Use synthetic examples only. Never use real customer, patient or company data.
