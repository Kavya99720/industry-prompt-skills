Voice only, so silence, noise, mishearing and spelled-out data are in scope. Each item shows where it is handled: "covered" with its rule, or "added" with the new rule or scenario. The owner asked for this run to save the list and add only what is missing in one step, without a confirm round; remove or re-mark any item and the matching addition will be taken out. ## Open questions

1. Whether the platform passes the contact's name and the call details on outbound calls is unconfirmed (as retail).
2. Silence, noise, interruptions and call drops are platform behaviours; nothing is written for them.
3. The student data rule defaults to none on a call, and v1 has no student lookup tool. If the business later wants verified sharing, a lookup tool and a check method are an owner decision.
4. Whether the booking tool fits a demo class or a counselling slot is unconfirmed (as real estate).
5. A fee-due or safety-notice outbound call beyond the four named purposes is not added.
